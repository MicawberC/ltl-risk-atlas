# CARLA Town02 switch failure

On 2026-10-14, `closed_loop_dynamic.py --town Town02 --methods fixed_hybrid fixed_warm_lp --plan-every 10 --sample-policy` called `client.load_world("Town02")` from a running CARLA 0.9.16 Town01 server. The CARLA process exited; the client reported a 120-second timeout while waiting for `127.0.0.1:2000`. No result was generated by that attempt, so it is excluded from timing comparisons. A fresh server later loaded `Town02_Opt` successfully; those separate results are in `closed_loop_town02opt_*.json`.
