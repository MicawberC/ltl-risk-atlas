# 补实验协议与记录口径

本目录是团队新增实验，不属于原作者 IROS 示例代码。运行入口为 `run_suite.py`、
`run_replay_suite.py` 和 `run_carla_suite.py`。完成后的结果与分析见 `README_CN.md`；
未完成的运行不得写成已通过。

## 输入与重复

主消融：24×24、32×32 的局部风险带，以及 16×16 的硬预算压力实例。
每例使用 73044、73045、73046 三个风险序列种子；每个种子独立计时三次，每次 20 个查询。
风险带使用 walk，压力例使用 iid。压力例人为增强奖励，明确作为辅助实验。

敏感性：另一种局部布局、0.2/0.8 变化幅度、walk/iid 更新、1/3/5 个变化方向，以及 160 查询长序列。
这些敏感性实验每组同一输入重复三次，仅评价计时波动，不声称三个独立输入样本。

每次各方法在新进程中运行；顺序预先由种子打乱。设置单线程，保基 LP 可行性容差 1e-9。
每个查询返回后独立评价策略；查询时间包含策略恢复，排除独立核验与公共模型构建。
自身初始化单独记录，同时纳入累计时间。

## 方法

- full：受控驱动下的完整缓存组合、区域价格检索、流式上界和按需扩充。
- no_mix：关闭缓存策略间的组合；完整 CMDP 回退允许生成随机策略，否则会改变优化问题。
- no_regions：使用固定候选价格的残差上界，关闭区域端点检索；扩充逻辑相同。
- no_stream：关闭单调上界档案和上一条区域快速路径，改为扫描策略库。
- forced_mdp：每次先求一个标量化 MDP；认证与必要扩充相同。
- frozen_lp：冻结初始化库，失败时调用保基 LP；用于诊断扩充价值。
- warm_lp：保留模型及 simplex basis，每次更新系数与必要的初始状态右端。

受控驱动复用生产求解器及实际 Bellman 残差上界，但不是旧查询路径的逐行副本。
受控完整版本的时间单独标为 full，不替换历史 CARLA 方法时间。

## 正确性与失败

检查动作概率非负、每状态概率和为 1；模型风险不超过 H；返回上下界差满足绝对/相对结合门槛。
独立策略评价与返回目标/风险的一致性阈值为 1e-5；风险核验阈值为 1e-7。
相同输入的 LP 值与返回上下界交叉核验，容差 1e-5。输入 theta 与起点序列保存哈希。
查询失败、超时、独立评价不一致均保留，不能用丢弃失败查询后的时间宣称加速。

诊断阶段发现近零状态的微小负 LP 占据量会被归一化放大成非法动作概率。
最终版本先作非负截断再归一化，增加回归测试；修复前运行不进入正式统计。
细节与数值证据保存在 `numerical_pilot.json`。

## 记录字段

保存 primal_i、primal_j、primal_weight、mixed_cache、上/下界、风险、实际独立评价、查询耗时、
标量化调用数、完整求解数、策略/档案规模、缓存数组与 LU 数据量、采样 RSS。
forced_mdp 的 direct_hit 是强制求解后的认证，不是零求解缓存命中。
缓存数据量不含全部对象开销；进程 RSS 包括保留的验证策略，不等于纯算法内存。

## CARLA

固定序列：四条既有每 tick 观测轨迹，同输入比较 full、warm_lp、no_stream，各重复三次。
这是新执行的规划器回放，不是新的闭环驾驶。求解计时和独立核验计时分开。

新闭环：Town01 路线 0 单/双行人、Town01 路线 1 单行人、Town02 路线 0 单行人，
每组计划三次重复，比较既有 observed-hybrid 与保基 LP。保留初始化失败、未到达、碰撞和规划异常。
同步仿真步长 0.05 秒；报告 P95、最大规划延迟和到达时间，不据此声称严格 20 Hz 实时。

高层期望折扣风险证书不等价于连续轨迹碰撞概率保证；前进/等待控制不是完整九动作的形式化精化。
多次计时也不代替风险映射校准、更多独立道路或系统文献新颖性比较。
