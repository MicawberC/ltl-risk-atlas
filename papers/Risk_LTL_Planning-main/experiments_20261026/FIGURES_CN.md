# 图片入口与图注口径

图片由 plot_results.py 从本批原始记录生成，PNG 与 SVG 同名。
所有范围均为本批观测到的最小—最大值，不是置信区间。

| 图片 | 含义 |
|---|---|
| [压力例消融](analysis/pressure_ablation.png) | 两条开发输入上，保基 LP、旧完整实现、缓存定价、定价加策略热启动的累计时间。每条输入重复计时三次；不能作为新序列上的独立消融结论。 |
| [全部配对时间比](analysis/paired_speedups.png) | 每点为一组相同输入的 LP/新版时间比，黑线为各批次中位数；大于 1 表示新版更快。重复计时和不同批次中的重叠输入不应当作独立道路。 |
| [留出新风险序列](analysis/heldout_configs.png) | 五个预先固定的新风险序列种子、三种既有配置，各重复三次。每个配置聚合 15 次计时，报告中位数与观测范围。 |
| [在线求解工作量](analysis/oracle_work.png) | 主实验中旧完整实现与新版的每查询普通 MDP 调用数，以及进入旧完整价格搜索程序的比例。调用数不含初始化，而累计计时包含自身初始化。新版定价本身也在求解约束规划问题。 |
| [160 次更新](analysis/long_sequence.png) | 同一长序列上三次计时的累计时间中位数与观测范围，包含各方法自身初始化。 |

详细时间、实际目标误差、尾延迟及适用范围见 [完整报告](README_CN.md)。
